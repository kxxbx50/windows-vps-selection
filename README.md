## 先确认三件事，再谈价格

### 一、Windows 授权归谁

市面上有三种做法，直接决定你要不要额外掏一笔钱：

**服务商随单提供并自动激活。** 下单选 Windows 镜像，开机就是已激活状态，最省事，价格里通常已经摊了授权成本。

**BYOL，自带密钥。** 你手上有零售密钥或企业协议，服务商只提供预装好的镜像，激活动作由你自己完成。云厂商普遍支持这种模式——已有授权的话不必重复买。

**评估版（Evaluation）先用着。** 免激活可用 180 天，够跑测试、学习和开发；到期不激活就没法继续用。

丽萨主机的套餐页面对这一点的表述是「支持安装 Windows」，没有写明授权由谁提供、是否随单激活。这是下单前必须开工单确认的第一个问题——它可能比套餐本身贵。

### 二、RDP 是入口，KVM 是后路

Windows VPS 用 RDP 连，默认端口 3389，开机后管理员密码发到邮箱，不需要手动配网络。Linux 那套 SSH 在这里用不上。

RDP 有一个麻烦：如果你在服务器上把防火墙规则改错了，或者网卡配崩了，RDP 会连不上，而你又没有别的入口。所以 KVM / VNC 网页控制台是否提供，比多数参数都重要——它是唯一的物理级后路。丽萨主机的套餐是 KVM 架构，这一项是满足的。

### 三、系统选定后能不能换

不同商家政策差得很远。IONOS 就明确写着：选了 Windows 虚拟服务器之后不能事后换成别的操作系统，要用 Linux 必须重新下单；想保留免费换系统的权利，得改买它的 Cloud Server 方案。

## 别家的价格表，容易被读错的地方

比价踩坑多半不是看错了配置，而是口径没统一。几个真实的例子：

Contabo 首页上 CLOUD VPS 6 的 **€7.50 是「前 24 个月」的价格**，不是长期价，续费按原价走。把它当成月费去和别家比，结论一定是错的。

home.pl 的兹罗提报价是 **netto 净价，不含 VAT**，而且按 **3 个月一期** 卖，部分档位首期还低于续期（XL 存储档首期 1380 zł、之后每期 1590 zł）。波兰站的报价直接乘汇率换算成人民币，会低估一成以上。

俄区商家习惯卢布月价加小时价双标，小时价看着很便宜，但月付换算下来未必划算；而且同一页面上的配置器单价和套餐表往往不是同一个口径。

磁盘容量也常被误读：标称 40GB 的盘，进系统看到 37GB 左右，是 1KB=1000B 与 1KB=1024B 的换算差，不是被偷了空间。

统一成「每月实付、含税、按续费价」再比，才有意义。
